# 주도성의 조화 — 학생주도성과 교사주도성

학생주도성의 중요성과 교사주도성과의 조화를 주제로 한 교육용 웹사이트입니다.
학생과 교사 모두가 활용할 수 있도록 설계되었습니다.

| 섹션 | 내용 |
| --- | --- |

| 조화의 원리 | 교사주도성과의 균형 (인터랙티브 슬라이더) |

## 교사 성찰 스튜디오

- **성찰일지**: 수업 성찰을 작성·저장(localStorage)·펼치기·삭제·텍스트 내보내기. 기록은 브라우저에만 저장됩니다.
- **AI 성찰 코치 에이전트**: 일지를 분석해 정서·주도성 요소(목소리/선택/소유권/성찰/안전/비계)를 진단하고, 반성 질문과 실천 제안을 생성합니다. 에이전트의 도구 실행 과정은 AGENT TRACE 로그로 표시되며, 이후 채팅으로 후속 질문이 가능합니다.
  - **LLM 모드**: 코치 패널의 [⚙️ LLM 연동 설정]에서 OpenAI 호환 API(OpenAI, OpenRouter, 로컬 프록시 등)를 연결하면 LLM이 더 깊이 분석하고 자연어 대화(스트리밍)가 가능합니다.
  - **규칙 모드**: 키를 입력하지 않으면 키워드 기반 규칙 엔진으로 자동 폴백되어 별도 설정 없이도 동작합니다.
- **수업 설계 어시스턴트**: 주제·목표·준비도·주도성 요소·비계를 입력하면 학생주도성 원리를 담은 수업 설계안(도입/전개/정리/비계/평가)을 생성합니다. 설계안은 일지에 저장하거나 복사할 수 있습니다.
- **주간 성찰 리포트**: 선택 기간(7/14/28일)의 일지를 모아 **반복되는 고민 · 성장 포인트 · 다음 주 목표**를 요약합니다. LLM 연결 시 AI가 리포트를 작성하고, 미설정 시 규칙 기반으로 요약됩니다.
  - **주도성 요소 레이더**: 기간 내 일지에 나타난 학생주도성 요소(목소리/선택권/소유권/자기성찰/안전한 실패/비계) 비중을 레이더 차트로 시각화.
  - **활동 히트맵**: 최근 12주 동안 날짜별 성찰 기록 수를 히트맵으로 표시 (진할수록 기록 많음).

## 기술 스택

- HTML / CSS / JavaScript (Vanilla) — 빌드 도구 없이 그대로 실행 가능
- 반응형 디자인, 접근성(ARIA) 고려

## 실행 방법

아무 정적 파일 서버로 열면 됩니다. 예:

```bash
# Node.js
npx serve .
# 또는 Python
python3 -m http.server 4173
```

브라우저에서 `http://localhost:4173` 접속.

## 파일 구조

```
index.html          — 페이지 구조와 콘텐츠
styles.css          — 디자인 (학생 주황 × 교사 남색 = 조화 그라데이션)
script.js           — 인터랙션 (탭·퀴즈·슬라이더·애니메이션)
agents.js           — 성찰일지 + 성찰 코치 에이전트(LLM/규칙) + 수업 설계 어시스턴트 + 주간 리포트(요약·레이더·히트맵)
mock-llm-server.js  — LLM 연동 테스트용 목 서버 (개발용)
```

## LLM 연동 방법

1. 성찰 코치 패널의 **⚙️ LLM 연동 설정**을 엽니다.
2. **API 주소**에 OpenAI 호환 엔드포인트를 입력합니다 (기본값 `https://api.openai.com/v1`).
   - OpenAI API는 브라우저 직접 호출이 CORS로 차단되는 경우가 있어, 브라우저 호출을 지원하는 **OpenRouter**(`https://openrouter.ai/api/v1`)나 **자신의 프록시 서버**를 권장합니다.
3. **API 키**와 **모델**(예: `gpt-4o-mini`)을 입력하고 [저장]을 누릅니다.
4. 모드 표시가 `🤖 LLM 모드`로 바뀌면 분석·대화가 LLM으로 동작합니다.
   - 키는 **이 브라우저의 localStorage에만 저장**되며 외부로 전송되지 않습니다.

### 오프라인 테스트

```bash
node mock-llm-server.js
```

실행 후 설정에서 API 주소를 `http://127.0.0.1:4180/v1`, 키·모델은 아무 값으로 지정하면
실제 API 키 없이 LLM 모드 전체 흐름(분석·스트리밍 대화·오류 폴백)을 테스트할 수 있습니다.
